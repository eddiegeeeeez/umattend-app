# Profile Settings Feature

This feature implements user profile settings following Bulletproof React architecture patterns.

## Structure

```
src/
├── features/profile/
│   ├── components/
│   │   ├── AcademicInfoForm.tsx      # Form to edit department/program
│   │   ├── LoginHistoryTable.tsx     # Table displaying login history
│   │   └── index.ts                  # Barrel exports
│   └── ...
├── app/profile/settings/
│   ├── layout.tsx                    # Settings page layout (inherited)
│   └── page.tsx                      # Main settings page with tabs
```

## Features

### 1. Academic Information Management
- **Component**: `AcademicInfoForm`
- **API**: `putUserMutation` (PUT /user)
- **Functionality**:
  - Edit department and program
  - Form validation with Zod schema
  - Automatic program filtering based on department
  - Optimistic UI updates
  - Sync with auth store
  - Query invalidation for consistency

### 2. Login History Viewer
- **Component**: `LoginHistoryTable`
- **API**: `getAuthLoginHistoryOptions` (GET /auth/login-history)
- **Functionality**:
  - Display login timestamp, IP address, device, and browser
  - Parse user agent for device/browser detection
  - Responsive table design
  - Loading skeleton states
  - Error handling with fallback UI

## API Integration

### Update User Profile
```typescript
putUserMutation({
  body: {
    department: string,
    program: string
  }
})
```

### Get Login History
```typescript
getAuthLoginHistoryOptions()
// Returns: Array<{
//   id: string,
//   timestamp: string,
//   ipAddress: string,
//   userAgent: string
// }>
```

## Architecture Patterns

### ✅ Bulletproof React Compliance

1. **Feature-based organization**: Components grouped under `features/profile/`
2. **Separation of concerns**: UI components separate from business logic
3. **Type safety**: Full TypeScript integration with autogenerated API types
4. **Error handling**: Proper error states and user feedback
5. **Loading states**: Skeleton loaders for better UX
6. **Responsive design**: Mobile-first with Tailwind breakpoints
7. **Accessibility**: Proper ARIA labels, keyboard navigation, focus management
8. **State management**: Zustand store integration for auth state
9. **Query management**: TanStack Query for server state
10. **Form validation**: React Hook Form + Zod schemas

## Usage

Navigate to `/profile/settings` or click "Account Settings" from the profile page.

### Academic Info Tab
1. Select department from dropdown
2. Select program (filtered by department)
3. Click "Save Changes" to update
4. Cancel button to reset form

### Login History Tab
- View recent login activity
- See timestamps, IP addresses, devices, and browsers
- Automatically fetches latest data
- Refreshes on tab switch

## Responsive Design

- **Mobile**: Stacked layout, simplified table
- **Tablet**: 2-column grid for better space usage
- **Desktop**: Full table with all columns visible

## Security Considerations

- Login history fetched server-side with auth token
- User can only update their own profile
- Form validation prevents invalid data submission
- Rate limiting handled by API layer
